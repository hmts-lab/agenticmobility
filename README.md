The project site of **AgMSim**, the Agentic Mobility Systems Simulator: a framework for researchers to build
their own agentic mobility systems and algorithms on, and to test them. Every participant can be an agent:
travellers, their cars, on-demand cars, transit, charging stations, traffic lights and the orchestrator of the
network.

- **Site, with the simulator running in the page:** <https://hmts-lab.github.io/agenticmobility/>
- **Source code of the simulator:** <https://github.com/hmts-lab/AgMSim>

This repository only serves the site (branch `gh-pages`). Its pages are written in `website/` of the AgMSim
repository and published from there with `sh website/publish.sh`.
